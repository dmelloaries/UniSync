# 🧩 UniSync – Real-Time Collaborative Platform

UniSync is a real-time collaborative platform designed for seamless teamwork on code, drawings, and documents — with live video/audio chat built-in.

![UniSync Banner](https://github.com/user-attachments/assets/6465669f-1b7a-4520-a271-68b1b8f84fe4)

---

## 🚀 Features

- ✨ **Google Authentication** – Simplified sign-in/sign-up with OAuth.
- 🔁 **Real-Time Collaboration** – Sync drawing, code, and docs using `Socket.io`.
- 🎥 **Live Video/Audio Chat** – Peer-to-peer communication via `WebRTC`.
- 🧠 **Intuitive UI** – Dynamic and responsive experience with `React + TypeScript`.
- 🗂️ **Project Persistence** – Store sessions, users, and shared data with `MongoDB`.

---

## 🔧 How UniSync Works

### ✅ User Authentication
- Google sign-in/sign-up to simplify access.

### 🔁 Real-Time Collaboration
- `Socket.io` manages real-time updates between users, ensuring synchronization during drawing, coding, and document creation.

### 📞 Live Video/Audio Communication
- `WebRTC` enables seamless peer-to-peer video calls during collaboration.

### 🛠️ Backend Infrastructure
- `Express` + `Node.js` server handles API requests.
- `MongoDB` stores user data and project collaboration details.

### 💻 Frontend Interaction
- Built with `React` and `TypeScript` for a dynamic, real-time UI.
